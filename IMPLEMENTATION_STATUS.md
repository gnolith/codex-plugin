# Sunset implementation status

The active Gnolith Setup plugin has been removed. The repository retains only:

- read-only legacy marker/config inspection;
- strict legacy operation-receipt parsing and summarization;
- secret redaction and credential-selector preservation;
- deterministic migration-bundle export and validation;
- compatibility fixtures and migration/security/archival documentation.

The `0.3.0` candidate remains private and unpublished. It is not deprecated,
tagged, or released. Alembic adoption and the independent checksum-bound
full-stack gate remain external acceptance prerequisites.
